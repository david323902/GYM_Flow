# GYM Flow – Plataforma de Gestión y Automatización para Gimnasios

## 📌 Descripción
GYM Flow es una plataforma web diseñada para la **gestión de usuarios, planes y procesos internos de un gimnasio**, integrando backend, frontend y automatización de tareas.  
El proyecto sigue una **arquitectura MERN**, con énfasis en seguridad, escalabilidad y mantenimiento.

## 🚀 Tecnologías Utilizadas

### Backend
- **Node.js** – Entorno de ejecución
- **Express.js** – Framework para API REST
- **MongoDB** – Base de datos NoSQL
- **Mongoose** – Modelado y validación de datos
- **JWT (JSON Web Token)** – Autenticación y autorización
- **Bcryptjs** – Encriptación de contraseñas
- **Nodemailer** – Envío de correos automáticos
- **Node-cron** – Tareas programadas (recordatorios y vencimientos)
- **Dotenv** – Gestión de variables de entorno
- **Cors** – Comunicación segura Frontend ↔ Backend

### Frontend
- **React** – Construcción de la interfaz de usuario
- **Vite** – Entorno de desarrollo y build rápido
- **Tailwind CSS** – Estilos modernos y responsivos
- **PostCSS & Autoprefixer** – Compatibilidad entre navegadores

### Automatización y Configuración
- **API REST** – Comunicación entre servicios
- **Arquitectura MERN** – Separación clara de responsabilidades
- **Buenas prácticas de seguridad** – Hashing, validaciones y control de acceso

## ⚙️ Funcionalidades Principales
- Gestión de usuarios y roles (admin / cliente)
- Autenticación segura con JWT
- Gestión de planes y vencimientos
- Envío automático de correos (notificaciones)
- Automatización de tareas con cron jobs
- Panel web para administración del sistema
